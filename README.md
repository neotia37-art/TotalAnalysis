# CANSLIM TERMINAL v3

종목코드(`005930`) 또는 티커(`NVDA`) 하나만 넣으면 8개 탭이 모두 갱신됩니다.
매일 아침 참고용으로 만든 오닐 기법 통합 터미널입니다.

## v3 배포하기

### 이미 앱이 있는 경우 (파일 교체)

1. GitHub 저장소 → `app.py` 클릭 → 오른쪽 위 **연필 아이콘**
2. `Ctrl+A` → `Delete` → 새 `app.py` 내용 전체 붙여넣기 → **Commit changes**
3. **새로 추가할 파일이 있습니다.** 저장소 첫 화면에서 `Add file` → `Create new file`
   - 파일명 칸에 `.streamlit/config.toml` 을 그대로 입력합니다(슬래시를 넣으면 폴더가 자동 생성됩니다)
   - 아래 내용을 붙여넣고 **Commit changes**

```
[theme]
base = "light"
primaryColor = "#8A5A00"
backgroundColor = "#FAF9F6"
secondaryBackgroundColor = "#F3F0EA"
textColor = "#16181C"

[server]
headless = true
```

4. 1~2분 뒤 앱 주소 새로고침. 화면이 그대로면 앱 오른쪽 위 `⋮` → **Reboot app**

> `.streamlit/config.toml`을 빼면 화면이 예전처럼 어둡게 나올 수 있습니다.
> `requirements.txt`는 v2와 동일하니 그대로 두세요.

### 처음 배포하는 경우

1. github.com 가입 → `New repository` (이름 아무거나, Public)
2. `Add file` → `Upload files` → `app.py`, `requirements.txt` 업로드 → `Commit changes`
3. `Add file` → `Create new file` → 파일명 `.streamlit/config.toml` → 위 내용 붙여넣기 → Commit
4. share.streamlit.io → `Continue with GitHub` → `New app`
5. Repository 선택 / Branch `main` / Main file path `app.py` → `Deploy`

### 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

국내 종목 위주라면 로컬 실행을 권합니다. 해외 서버에서는 네이버 접속이 막혀
분기 실적표와 국내 뉴스를 못 가져오는 경우가 있습니다.

## v3 신규 사항

**1. 시장 — 미국 3지수 + 매수 적합도**
다우존스·S&P 500·나스닥을 각각 FTD, 분산일, 50/200일선으로 판정합니다.
그 위에 **오늘 매수하기 좋은 날인가**를 100점으로 환산합니다:
시장 국면 40 + 분산일 20 + FTD 경과일 15 + 추세 정렬 15 + 당일 등락 10.
75점 이상 적극, 55~74 선별, 35~54 소극, 35 미만 보류. 최근 120일 추이도 그래프로 봅니다.

**2. 환율**
USD/KRW 10년치를 자동 수집해 1·6·12·24·36개월 평균과 현재 위치, 3년 백분위,
추세(20/60/120일선), RSI, 변동성을 냅니다.
기간별 전략은 1개월=단기 모멘텀, 3개월=평균 회귀, 6개월=중기 밴드, 1년=장기 위치로
각각 판단이 다릅니다. 백분위에 따라 **지금 환전할 비중(5~70%)**과 나머지 분할 트리거 가격을 제시합니다.
미국 종목을 보고 있으면 피봇의 원화 환산가도 같이 보여줍니다.

**3. 개별종목 — 고점/저점/매도 신호 추가**
오닐의 고점 신호 6종(클라이맥스 급등, 200일선 이격, 최대 상승일, 최대 거래량 음봉,
소진 갭, 레일로드 트랙)과 바닥 신호 5종(언더컷&랠리, 3주 타이트, 거래량 건조,
대량 매수 출현, 50일선 지지)을 측정값과 함께 판정합니다.
이를 종합한 **매도 압력 0~100점**과 권고(보유/경계/절반 익절/전량 검토), 8주 보유 규칙 판정을 냅니다.

**4. 모든 판정에 근거 표시**
카드마다 측정값·기준·충족 여부가 붙고, 주요 STEP에는 근거 목록이 따로 나옵니다.
해석 박스는 오닐이 왜 그 기준을 썼는지를 쉬운 말로 풀어줍니다.

**5. 정밀 보강 (기본 CANSLIM에 없는 항목)**
- ATR 기반 손절폭 적정성 — 변동성 큰 종목에 일괄 -8%를 쓰면 정상 흔들림에 손절됩니다
- 유동성(20일 평균 거래대금)과 내 주문 비중
- 다음 실적 발표일 D-day, 과거 갭 상위 5%
- 이 종목의 과거 베이스 돌파 승률
- 시장 폭(3개월 상승 종목 비율)
- 매수 전 12항목 최종 체크리스트

**6. 뉴스**
로이터·블룸버그·WSJ·CNBC·배런스·IBD(국내는 연합뉴스·한국경제·매일경제 등)만 남기고
나머지는 걸러냅니다. 제목 키워드로 10개 주제(실적/신제품/수주/증설/애널리스트/기관수급/
M&A/규제소송/공급망/인사)와 논조를 분류하고, 각 주제를 CANSLIM 글자에 연결해 시사점을 씁니다.

**7. 누적 스캔**
추가한 종목이 `watchlist.json`에 저장돼 새로고침해도 남습니다.
현재 보고 있는 종목을 버튼 하나로 추가할 수 있고, 목록 직접 편집·기본값 복원도 됩니다.

**8. 화면**
검정 배경을 밝은 종이색(#FAF9F6)으로 바꾸고 본문 대비를 높였습니다.
제목은 명조(Noto Serif KR), 숫자는 고정폭(IBM Plex Mono), 본문은 Pretendard입니다.

## 한계

- EPS Rating·SMR·Composite·매수 적합도는 IBD 원본이 아닌 자체 환산 **근사값**입니다.
- 뉴스 주제·논조는 제목 키워드 기반 자동 분류라 참고용입니다. 본문 확인이 필요합니다.
- 국내 분기 EPS는 네이버 실적표 파싱에 의존합니다. 비면 앱 안에서 직접 입력할 수 있습니다.
- 업종 순위는 미국(11개 섹터 ETF)만 지원합니다.
- 미국 RS Rating은 유동성 상위 약 190종목 기준 근사치입니다.
- `watchlist.json`은 앱 서버에 저장되므로 재배포하면 초기화될 수 있습니다. 목록은 따로 복사해 두세요.
